## 🚀 3 BƯỚC UPLOAD LÊN TÊN MIỀN model3d.wuaze.com:

### BƯỚC 1: Đăng nhập InfinityFree
- Truy cập: https://dash.infinityfree.com/
- Bấm vào tài khoản của bạn: **`if0_42932265`** (Domain: `model3d.wuaze.com`).
- Chọn nút **File Manager** (Trình quản lý tệp).

### BƯỚC 2: Vào thư mục chứa web (htdocs)
- Trong File Manager, bấm mở thư mục **`htdocs`** (hoặc `model3d.wuaze.com/htdocs`).
- **LƯU Ý:** Nếu trong thư mục `htdocs` đang có sẵn các file mặc định như `index2.html` hoặc `default.php`, hãy chọn và xóa (Delete) chúng đi để tránh xung đột.

### BƯỚC 3: Upload và Giải Nén
Có 2 cách cực kỳ nhanh:

* **CÁCH A (Nhanh nhất - Dùng file ZIP):**
  1. Trong File Manager, nhìn thanh công cụ bên dưới hoặc nút menu, bấm biểu tượng **Upload Zip** (hoặc nút Upload).
  2. Chọn file: `model3d_infinityfree_upload.zip` (đã tạo sẵn trên Desktop và trong thư mục dự án).
  3. Bấm xác nhận giải nén (**Upload and Extract**).
  4. Đảm bảo các file `index.html`, `slides.html` và thư mục `assets` nằm ngay bên trong thư mục `htdocs`.

* **CÁCH B (Kéo thả trực tiếp):**
  1. Mở thư mục `standalone_infinityfree` trên máy tính.
  2. Kéo thả toàn bộ: `index.html`, `slides.html` và thư mục `assets` vào thẳng giao diện File Manager của `htdocs`.
