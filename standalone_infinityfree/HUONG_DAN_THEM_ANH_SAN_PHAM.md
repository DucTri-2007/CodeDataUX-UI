# HƯỚNG DẪN THÊM VÀ SỬ DỤNG ẢNH SẢN PHẨM 3D MỚI

Thư mục này dùng để chứa tất cả các hình ảnh sản phẩm mô hình 3D mới mà bạn muốn tải lên website:
- **Đường dẫn thư mục**: `assets/images/products/`

---

## 3 BƯỚC ĐỂ THÊM VÀ HIỂN THỊ SẢN PHẨM MỚI LÊN WEB:

### BƯỚC 1: Lưu file ảnh vào thư mục này
1. Chuẩn bị ảnh mô hình 3D của bạn (định dạng `.png`, `.jpg`, `.jpeg`, hoặc `.webp`).
2. Copy (chép) file ảnh vào thư mục: `assets/images/products/`
   * *Ví dụ: bạn đặt tên ảnh là `gundam-rx78.png` hoặc `luffy-gear5.jpg`.*

### BƯỚC 2: Đăng nhập quyền ADMIN trên Website
1. Mở website `index.html`.
2. Bấm vào nút **`👤 Tài Khoản`** ở góc trên bên phải.
3. Bấm nút: **`🛡️ ĐĂNG NHẬP ADMIN (QUẢN TRỊ VIÊN)`** (hoặc nhập tài khoản `admin` / mật khẩu `admin`).
4. Header sẽ hiện huy hiệu: **`🛡️ ADMIN: Quản Trị Viên`** cùng nút **`⚙️ QUẢN TRỊ HỆ THỐNG`**.

### BƯỚC 3: Thêm sản phẩm qua Bảng Điều Khiển ADMIN
1. Bấm vào nút **`⚙️ QUẢN TRỊ HỆ THỐNG`**.
2. Chọn tab: **`➕ Thêm / Xóa Sản Phẩm`**.
3. Điền thông tin:
   - Tên mô hình (ví dụ: *Mô hình Gundam RX-78-2 30cm*)
   - Phân loại / Danh mục (Model Nam / Nữ / Figure)
   - Giá bán & Giá gốc
   - Tại ô **Đường Dẫn Ảnh Sản Phẩm**: bạn chỉ cần nhập:
     `assets/images/products/gundam-rx78.png`
     *(hoặc chọn nhanh các ảnh gợi ý có sẵn)*
   - Số lượng tồn kho ban đầu (ví dụ: 15)
4. Bấm nút **`➕ THÊM SẢN PHẨM VÀO WEBSITE`**.

🎉 **Xong!** Sản phẩm mới sẽ lập tức xuất hiện ngay trên Cửa Hàng Trang Chủ, cho phép khách hàng bấm xem chi tiết, chọn kích thước và thêm vào giỏ hàng bình thường!
